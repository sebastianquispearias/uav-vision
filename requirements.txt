# What this repository needs, measured from the imports of its own source.
#
# The package itself (uav_vision/) needs only numpy. Everything below it is needed by the
# scripts, the tests and the ground station, which is why they are not dependencies of the
# package: `pip install -e .` installs the library, and this file installs the workbench.
#
#   pip install -r requirements.txt
#
# THE GrADyS RUNTIME IS A SEPARATE PUBLIC REPOSITORY and it is not on PyPI. Without it,
# vision_protocol.py cannot be imported, so demo/demo.py and 12 of the 50 tests do not run.
# It is listed here because the first command in the README depends on it.
numpy>=1.24
# HEADLESS and not opencv-python: nothing in this repository opens a window -- no imshow, no
# namedWindow, no waitKey -- because the station and the labelling tool draw to JPEG. The normal
# wheel wants libGL.so.1, which a machine with no desktop does not have, and then the import
# fails with an error that never mentions the desktop.
opencv-python-headless>=4.8
scipy>=1.10

# The GrADyS embedded runtime: the protocol interface, and the message types a protocol sends.
gradys_embedded @ git+https://github.com/Project-GrADyS/gradys-embedded.git
